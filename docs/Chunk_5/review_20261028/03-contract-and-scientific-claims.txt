2: 
3: Research-only increment. template_investigation.py implements fitted comparisons

7: 
8: ## Executed numerical workflow
9: 
10: The invented template grid has 21 feature centers, 64 explicit bins over 1–2
11: microns, known Gaussian LSF sigma 0.02 micron and feature width 0.035 micron.
12: Analytic convolution and bin averaging use the preceding research harness.
13: Generalized least squares fits a constant plus a signed template amplitude, with
14: the same fixed covariance and data for every candidate. Amplitude is unconstrained:
15: negative features count in this two-sided experiment. It is not an abundance.
16: 
17: Cholesky whitening implements the specified positive-definite covariance. Fitted
18: baseline and feature amplitude are removed before calculating residual improvement
19: relative to a fitted constant-only null. An independent full-design least-squares
20: solve checks coefficients and residuals. Noiseless input recovers the known baseline,
21: amplitude and center. Degenerate templates, nonfinite inputs, incompatible shapes,
22: asymmetric and non-positive-definite covariance are rejected by the numerical API.
23: This array API assumes explicit common-grid/units; it is not a metadata validator.
24: 
25: The Monte Carlo uses known Gaussian AR(1) noise, rho=0.65 and sigma=0.01 percentage
26: points. Three separate seeded generators produce 2,000 calibration null draws,
27: 2,000 held-out null draws and 500 injected draws. Calibration takes the higher
28: empirical 95th percentile; thresholds are frozen before evaluating holdout draws.
29: Baseline fitting and the complete grid search are repeated for every draw.
30: 
31: | Held-out procedure | Threshold | Exceedances |
32: | --- | ---: | ---: |
33: | One fixed template | 3.8239 | 78/2000 = 3.9% |
34: | Search 21 templates, incorrectly reuse fixed-template threshold | 3.8239 | 1221/2000 = 61.05% |
35: | Search 21 templates, use full-search null threshold | 9.0968 | 110/2000 = 5.5% |
36: 
37: Binomial standard errors are recorded in the JSON (about 0.51 percentage points
38: for the final row); they omit uncertainty from finite calibration samples. No
39: exact population error-rate guarantee or rare-tail significance is claimed.
40: 
41: For invented amplitude 0.06 at the center template, 489/500 injected runs exceed
42: the search threshold; 496/500 recover the exact grid center. These are separate
43: metrics: matching the center does not require exceeding a threshold. Median fitted
44: amplitude at the true center is 0.06040. Recovery at this favorable synthetic
45: amplitude does not validate weaker signals, unknown covariance or real molecules.
46: 
47: ## Source context and physical-model requirements

50: excess from searching across a range. Our independent Monte Carlo illustrates

54: generates transit radii from temperatures, composition, gravity, radius and a
55: reference pressure, then converts radii using stellar radius. Model and observation
56: units must match. This establishes a concrete distinction between a fitted feature
57: and atmospheric forward modelling; no tutorial parameters are adopted for WASP-39 b.
58: Sources read 2026-10-28; no datasets or dependencies downloaded.
