16: def fit_templates(observations, templates, covariance):
17:     """GLS fits baseline + signed amplitude for each fixed template.
18: 
19:     observations: (draws, bins); templates: (bins, candidates); covariance:
20:     (bins, bins), known and fixed, positive definite. Candidates use the same data,
21:     units and covariance. Returns null improvement, NOT a detection significance.
22:     """
23:     y, models, cov = (np.asarray(v, dtype=float) for v in (observations, templates, covariance))
24:     if y.ndim != 2 or models.ndim != 2 or cov.ndim != 2:
25:         raise ValueError('Require observations and templates matrices and square covariance')
26:     draws, bins = y.shape
27:     if not draws or bins < 3 or models.shape[0] != bins or not models.shape[1] or cov.shape != (bins, bins):
28:         raise ValueError('Incompatible or empty input dimensions')
29:     if not all(np.isfinite(v).all() for v in (y, models, cov)):
30:         raise ValueError('Require finite inputs')
31:     if not np.allclose(cov, cov.T, rtol=1e-12, atol=0):
32:         raise ValueError('Covariance must be symmetric')
33:     try:
34:         chol = np.linalg.cholesky(cov)
35:     except np.linalg.LinAlgError as error:
36:         raise ValueError('Covariance must be positive definite') from error
37:     white_y = np.linalg.solve(chol, y.T).T
38:     white_models = np.linalg.solve(chol, models)
39:     white_one = np.linalg.solve(chol, np.ones(bins))
40:     one_norm = white_one @ white_one
41:     base_null = white_y @ white_one / one_norm
42:     residual_y = white_y - base_null[:, None]*white_one
43:     model_mean = white_one @ white_models / one_norm
44:     residual_models = white_models - white_one[:, None]*model_mean
45:     model_norm = np.sum(residual_models**2, axis=0)
46:     if np.any(model_norm <= np.finfo(float).eps*np.sum(white_models**2, axis=0)):
47:         raise ValueError('Template is degenerate with fitted constant baseline')
48:     projection = residual_y @ residual_models
49:     amplitudes = projection / model_norm
50:     improvement = projection**2 / model_norm
51:     null_q = np.sum(residual_y**2, axis=1)
52:     return {'improvement': improvement, 'amplitudes': amplitudes,
53:             'baselines': base_null[:, None]-amplitudes*model_mean,
54:             'null_quadratic': null_q, 'best_index': np.argmax(improvement, axis=1)}

11: microns, known Gaussian LSF sigma 0.02 micron and feature width 0.035 micron.
12: Analytic convolution and bin averaging use the preceding research harness.
13: Generalized least squares fits a constant plus a signed template amplitude, with
14: the same fixed covariance and data for every candidate. Amplitude is unconstrained:
15: negative features count in this two-sided experiment. It is not an abundance.
16: 
17: Cholesky whitening implements the specified positive-definite covariance. Fitted
18: baseline and feature amplitude are removed before calculating residual improvement
19: relative to a fitted constant-only null. An independent full-design least-squares
20: solve checks coefficients and residuals. Noiseless input recovers the known baseline,
21: amplitude and center. Degenerate templates, nonfinite inputs, incompatible shapes,
22: asymmetric and non-positive-definite covariance are rejected by the numerical API.
23: This array API assumes explicit common-grid/units; it is not a metadata validator.
24: 
25: The Monte Carlo uses known Gaussian AR(1) noise, rho=0.65 and sigma=0.01 percentage
26: points. Three separate seeded generators produce 2,000 calibration null draws,
27: 2,000 held-out null draws and 500 injected draws. Calibration takes the higher
28: empirical 95th percentile; thresholds are frozen before evaluating holdout draws.
29: Baseline fitting and the complete grid search are repeated for every draw.
