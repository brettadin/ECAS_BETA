# ECAS — Local Spectral Reference Library Checklist

The proposed direction is to shift ECAS away from unreliable online molecular-spectrum searching and toward a locally stored, curated reference library. Online sources would remain useful for obtaining data, but ECAS would primarily use files already downloaded and catalogued.

The initial checklist should cover three distinct resources:

1. Molecular reference spectra — real laboratory measurements or validated calculated spectra for identifying candidate compounds.
2. Atomic spectral references — elemental emission and absorption lines, particularly for UV-Vis and astronomical spectroscopy.
3. Exoplanet transit observations — actual planetary transit datasets, kept separate from laboratory molecular references.

These are different kinds of scientific data and should not be treated as interchangeable.

## 1. How to use this checklist

For each species, the goal is to obtain whatever suitable data are available, rather than requiring every species to have every type of spectrum.

- IR reference spectrum, preferably covering a useful portion of the mid-IR.
- UV-Vis reference spectrum, where meaningful and available.
- Gas-phase spectrum.
- Liquid-phase spectrum, where meaningful.
- Solid-phase spectrum, where meaningful.
- Relevant temperature and pressure recorded.
- Original data file downloaded and preserved.
- Source, citation, units, and data provenance recorded.

Important: Phase is part of the measurement conditions, not simply a property of the molecule. A gas-phase spectrum and a liquid-phase spectrum of the same compound can have substantially different band positions and shapes. Some species also decompose or react before all three phases can be measured conveniently.

For exoplanet applications, gas-phase data and suitable temperature-dependent molecular absorption data are especially important. For conventional laboratory FTIR and UV-Vis identification, condensed-phase references can also be valuable.

### Recommended collection order

1. NIST: common laboratory compounds, measured IR, and available UV-Vis spectra.
2. HITRAN: molecular gas-phase cross-sections and conditions suitable for atmospheric work.
3. ExoMol: additional molecules and hot-atmosphere line lists.
4. NIST ASD: atomic and ionic spectral lines.
5. Manual or specialized sources for compounds not covered by those databases.

Bulk acquisition is feasible in principle, but the exact automation depends on each source's access method, file formats, and redistribution terms. We should not scrape an entire database blindly or assume its full contents can legally be bundled with ECAS.

## 7. What each local dataset needs

Regardless of source, every file should have a corresponding metadata record.

| Field              | Example or purpose                                         |
| ------------------ | ---------------------------------------------------------- |
| Species            | Water, H₂O                                                 |
| Dataset type       | Measured spectrum, line list, cross-section                |
| Spectral region    | IR, UV, visible                                            |
| Phase              | Gas, liquid, solid, or not applicable                      |
| Measurement method | FTIR, UV-Vis, computed line list                           |
| Conditions         | Temperature, pressure, solvent, concentration              |
| X-axis             | Wavelength or wavenumber, including units                  |
| Y-axis             | Absorbance, transmittance, cross-section, line intensity   |
| Source             | Database and original record identifier                    |
| Citation           | DOI, publication, or source reference                      |
| File               | Relative path to the original data                         |
| Processing         | Any conversion, interpolation, smoothing, or normalization |
| Usage rights       | License or redistribution conditions                       |

Keep the original file unchanged. Any normalized, resampled, or otherwise processed version should be a separate derived artifact with its processing history recorded.

Do not start by manually downloading every compound in the lists. That could create a large collection with inconsistent formats and missing metadata.

The better next step is to make a master inventory containing all the species above, then determine which spectra each source actually offers. From that inventory, we can produce:

- A missing-data list for manual acquisition.

This collection plan should remain separate from implementation changes for now. Once the inventory and data strategy are established, we can plan the redesign of the Identify tab around local references and separately assess how much of the ECAS v1 transit tab can be reused.

## How to run it

### 1. Create the inventory first

Save the downloaded script somewhere convenient. Open a terminal in that folder and run:

```
python ecas_spectral_collector.py
```

This creates an `ECAS_Spectral_Library` folder containing:

- `inventory/ecas_spectral_inventory.csv` — the full target inventory.
- `inventory/phase_coverage.csv` — a checklist showing which states and environments need reference data.
- `inventory/metadata_template.json` — fields to record for each dataset.
- `raw/` — intended location for original downloads.
- `processed/` — reserved for later processing.
- `logs/` — collection logs and reports.

This first step does not download anything.

### 2. Preview a database download

Install the downloader:

```
python -m pip install pyexocross
```

Then generate a HITRAN URL plan without downloading files:

```
python ecas_spectral_collector.py --source hitran --plan-only
```

The script also supports `--source exomol` and `--source atoms`. Check the generated URL lists and estimated scope before proceeding.

### 3. Start with a small download

After reviewing the plan and relevant database terms, an actual HITRAN download can be started with:

```
python ecas_spectral_collector.py --source hitran --confirm-download
```

The configured species list is a starting subset, not exhaustive coverage. Check the report and logs for unavailable species or failed requests.

## What remains to make the collection comprehensive

The next version should add three capabilities before we treat this as a complete ECAS library:

1. Automated NIST laboratory-spectrum retrieval for available IR and UV-Vis records, including phase, sample preparation and source references.
2. Database discovery, so the collector can find available species and isotopologues rather than relying only on a hard-coded list.
3. Coverage verification, so each molecule or element is marked separately for measured gas-phase spectra, liquid-phase spectra, solid-phase spectra, line lists and cross-sections.

We should also preserve the distinction between measured spectra and spectra calculated from line lists. That distinction will matter when ECAS compares laboratory measurements against astronomical observations.

Recommendation: Run the inventory-only mode first and inspect the CSV files. The current script is a useful starting point, but it is not yet the complete automated download system you ultimately need.
