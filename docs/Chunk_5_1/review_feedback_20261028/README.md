# Argon interactive review batches

Open each numbered .txt and paste its entire contents into a separate Argon review.
Return each JSON report to the coordinator. Numbered lines refer to original source
files; manifest.json binds prompts and source hashes to this working snapshot.
Five independent batches intentionally overlap integration dependencies. Review
prompts include complete listed files, not just changed hunks. No review is claimed
complete by the original preparation of these prompts. All five zero-findings
reports have since been received; see RECEIVED_REPORTS.md for scopes and disposition.
Large prompts may need file upload in the interactive app rather than a
single paste; preserve filenames and request another batch if context is truncated.
The sibling handoff records verification, open acceptance and recovery instructions.
