RAW/PREPARED CORRESPONDENCE

All 18 raw files have matching prepared files with the same relative paths.

Comparison of the current archive confirms that the corresponding raw and prepared files are byte-for-byte identical.

The Ready_For_ECAS/IR directory therefore currently contains copies of the source JCAMP-DX files. It does not represent a separate conversion, normalization, interpolation or resampling operation.

SCIENTIFIC METADATA

The files contain individual JCAMP-DX metadata. These records must be consulted when selecting or interpreting a spectrum.

Metadata can include:
    Molecular identity
    Sample phase
    X-axis units
    Y-axis units and signal type
    Spectral range
    Resolution
    Temperature and pressure
    Instrument and sample conditions
    Source and digitization information

The collection does not contain one uniform measurement type. Some files represent absorbance, while others represent transmittance. Sample conditions and provenance also vary.

The H2O collection includes both a gas-phase spectrum and a liquid-phase spectrum.

A spectrum's presence in the library does not establish that it is suitable for every scientific application or directly comparable with another spectrum.

VALIDATION LIMITATIONS

This inventory verifies file presence and raw/prepared correspondence. It does not certify:
    Full JCAMP-DX compliance
    Measurement accuracy
    Calibration
    Scientific suitability
    Compatibility between different signal types
    Compatibility between different sample phases or conditions

The previous 72-file validation report described an earlier collection and used paths that do not correspond to the current library structure. Its point-count mismatch results must not be interpreted as validation results for the current 18 files.

HISTORICAL RECORDS
